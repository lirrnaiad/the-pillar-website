# Font Files Setup

## Elgraine Black Font

To use the **FONTSPRING DEMO - Elgraine Black** font, please add the font files to this directory.

### Required Font Files:

Place one or more of these formats in this directory:

- `FontspringDemo-ElgraineBlack.woff2` (recommended)
- `FontspringDemo-ElgraineBlack.woff`
- `FontspringDemo-ElgraineBlack.ttf`

Or alternatively:

- `ElgraineBlack-Regular.woff2`
- `ElgraineBlack-Regular.woff`
- `ElgraineBlack-Regular.ttf`
- `ElgraineBlack-Bold.woff2`
- `ElgraineBlack-Bold.woff`
- `ElgraineBlack-Bold.ttf`

### Where to Get the Font:

1. Purchase the full license from [Fontspring](https://www.fontspring.com/)
2. If you have the font files, copy them to this directory
3. The font will automatically be applied to all headings and body text once the files are in place

### Font Usage:

The font is configured to be used as:
- **Heading font**: `--font-family-heading`
- **Body font**: `--font-family-body`

Both are set to use "FONTSPRING DEMO - Elgraine Black" as the primary font.
